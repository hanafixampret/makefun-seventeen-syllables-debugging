A [make.fun](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) entry: one debugging haiku, three lines in the 5-7-5 shape.

`main.ts` (Node 22+, stdlib only) writes the haiku to `/output/entry.txt` and
self-checks the 5-7-5 syllable count before writing:

```text
two days hunting ghosts
the bug lived in my dead code
I delete, it heals
```

Run it with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` lands.
